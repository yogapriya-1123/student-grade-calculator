# Student Grade Calculator 🐍

A beginner Python project that calculates a student's total marks, average, and grade.

## Features

- Takes student name as input
- Accepts marks for Maths, Science, and English
- Calculates total marks
- Calculates average marks
- Assigns a grade
- Validates marks between 0 and 100

## Grade System

| Average | Grade |
|---------|-------|
| 90–100  | A |
| 75–89   | B |
| 60–74   | C |
| 50–59   | D |
| Below 50 | F |

## Technologies Used

- Python 3
